# Инструкции репозитория Calendorama

- Начинайте работу с [`doc/README.md`](doc/README.md) и прочитайте документ о
  затрагиваемой части приложения.
- Источниками истины являются исполняемый код, тесты, конфигурация и lock-файлы.
- Если изменение делает документацию неточной, обновите соответствующий
  документ в той же задаче.
- [`DEPLOYMENT.md`](DEPLOYMENT.md) содержит декларативный контракт приложения с
  окружением размещения.
- Production-инфраструктура, выполнение deploy и rollback, а также серверные
  runbooks находятся вне ответственности этого репозитория; не дублируйте их
  здесь.
